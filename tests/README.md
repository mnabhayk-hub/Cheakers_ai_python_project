
# Checkers AI

An intelligent American Checkers game developed using
Python and Pygame.

## Features

- American Checkers rules
- Human vs AI gameplay
- Minimax algorithm
- Alpha-Beta Pruning
- Greedy Best-First Search
- AI performance comparison
- Search statistics and visualization

## Technologies

- Python
- Pygame
- NumPy
- Matplotlib
- Pytest

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Navigate into the project:

cd CHECKERS_AI

Install dependencies:

pip install -r requirements.txt

## Run the game

python main.py

## Run benchmarks

python -m analytics.benchmark

## Run tests

pytest -v

## Algorithms

1. Minimax
2. Alpha-Beta Pruning
3. Greedy Best-First Search
